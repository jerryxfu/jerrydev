The first computers were excellent at what humans find hard (calculating, sorting, applying rules) and hopeless at what
humans do without thinking: recognizing a face, understanding a sentence, catching an object. Modern artificial
intelligence grew out of that paradox, and out of one idea: instead of writing the rules, we could make machines learn
them.

## 2. Programming rules versus learning from data

An ordinary program is a list of rules written by a human: *if* the sensor reads this, *then* do that. It works as long
as someone can write the rules. For recognizing a cat in a photo, nobody knows how to write the rule.

Machine learning flips the process. We give the machine examples and the expected answers, and it builds the rule
itself, as a function with millions of parameters adjusted until its answers match the examples. The programmer no
longer writes the solution; they write the way of learning it.

## 4. What "learning" means

The classic definition is Tom Mitchell's: a program learns from experience $E$ with respect to a task $T$ and a
performance measure $P$ if its performance on $T$, as measured by $P$, improves with $E$.

In other words, three things are needed: a task (recognize a digit), a way of measuring success (the percentage of
digits classified correctly), and experience (thousands of labeled images). The task is not to learn; the task is to
recognize the digit. Learning is what happens when $P$ goes up.
