There is nothing mysterious about a neural network: it is a function. Numbers go in, numbers come out, and in between it
does nothing but multiplications, additions and a few simple functions applied millions of times. What makes it
interesting is that its parameters are not written by a human: they are adjusted automatically until the function does
what we want.

## 2. The neuron

A neuron takes inputs $x_1, \dots, x_n$, forms a weighted sum with weights $w_1, \dots, w_n$, adds a bias $b$, then
applies an activation function $\sigma$:

$$
y = \sigma\!\left( \sum_{i=1}^{n} w_i x_i + b \right) = \sigma\!\left( w^\top x + b \right)
$$

The weights say how much each input matters, the bias shifts the threshold, and the activation (ReLU, sigmoid, tanh)
brings the non-linearity without which stacking neurons would be pointless: a sum of weighted sums is still a weighted
sum.

## 3. Layers

A network stacks layers of neurons: each neuron in a layer reads every output of the previous one. For a whole layer,
the weights form a matrix $W$ and the computation becomes a matrix-vector product:

$$
h = \sigma(W x + b)
$$

This is the single most frequent operation in all of deep learning, and the reason graphics cards, built to multiply
matrices, made the field possible.

## 6. The training loop

<Callout kind="important" label="TODO">
Epochs, batches, the loss curve, when to stop. Then the workshop: a network on MNIST in a few lines of PyTorch in a
notebook, with a link to a ready-to-run notebook.
</Callout>

```python
# Workshop skeleton, to finish and test.
import torch
from torch import nn

model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(28 * 28, 128),
    nn.ReLU(),
    nn.Linear(128, 10),
)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for images, labels in train_loader:      # one batch at a time
    loss = loss_fn(model(images), labels)  # how wrong we are
    optimizer.zero_grad()
    loss.backward()                        # backpropagation
    optimizer.step()                       # one step of descent
```
