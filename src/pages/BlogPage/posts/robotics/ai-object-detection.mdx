AprilTags are designed to be found; a game piece is not. To recognize an arbitrary object in an image, nobody knows how
to write the rules, so we learn them: neural object detection. This lesson explains how a network goes from a grid of
pixels to a list of boxes, each with a label and a score.

</Callout>

## 2. The convolution: a filter that learns

<Callout kind="important" label="TODO">
A filter is a small grid of weights slid across the image; the result highlights a pattern (edge, corner, texture). In a
convolutional network (CNN) the filter weights are learned, and successive layers detect increasingly abstract patterns.
Why this solves the factors-of-variation problem: the same filter applies everywhere in the image. Animation or figure
of a $3 \times 3$ convolution.
</Callout>

## 4. Measuring a detector

Intersection over Union (IoU) measures how much a predicted box overlaps the expected one: the area of their
intersection divided by the area of their union, from 0 (no overlap) to 1 (identical). A prediction counts as correct
above a threshold, commonly 0.5.

$$
\text{IoU} = \frac{\text{area}(A \cap B)}{\text{area}(A \cup B)}
$$
