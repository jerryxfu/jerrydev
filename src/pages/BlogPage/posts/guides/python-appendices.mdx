## Gotchas that eat up hours

1. **`=` vs `==`.** Assignment versus comparison.
2. **`^` is not a power.** It's bitwise XOR — `2 ^ 3` is `1`, not `8`. Use `**`.
3. **Indices start at 0**, and ranges and slices **exclude the end**. `range(1, 10)` stops at 9.
4. **Never compare floats with `==`.** Compare with a tolerance.
5. **`input()` returns a string.** Convert it.
6. **Lists don't do maths.** `[1, 2] * 2` is `[1, 2, 1, 2]`. Use a NumPy array.
7. **Assignment doesn't copy.** `b = a` for a list or array means one object with two names.
8. **Mutable default arguments** are shared between calls. Use `None`.
9. **Modifying a list while looping over it** skips elements. Loop over a copy.
10. **Don't name files after packages.** A local `math.py` or `random.py` breaks imports.
11. **`//` truncates.** `1 // 2` is `0`, and it fails silently.
12. **Trig functions take radians.**
13. **In NumPy masks, use `&` and `|`**, not `and`/`or`, and parenthesise each condition.
14. **`np.argmax` gives an index**, `np.max` gives a value.
15. **`plt.show()` blocks** until you close the window.
16. **Writing to a file needs explicit `\n`**, or everything lands on one line.
17. **A bare `except:`** hides your own bugs. Catch specific exceptions.
18. **`ModuleNotFoundError` for something you installed** means you're in a different environment than you think.

## Where to go next

**Official** — [docs.python.org/3/tutorial](https://docs.python.org/3/tutorial/) is genuinely good and often overlooked.
The [library reference](https://docs.python.org/3/library/) is where you look things up.

**Practice** — [Exercism](https://exercism.org/tracks/python) has small problems with mentor feedback. [Advent of Code](https://adventofcode.com/) is a yearly
set of puzzles that ramp up nicely. Best of all: pick something you actually want to exist and build it badly.

**Books** — *Automate the Boring Stuff* (free online) for practical scripting, *Fluent Python* once you want to know why Python works the way it does.

**Libraries worth knowing about** — `requests` for HTTP, `pandas` for tabular data, `pytest` for tests, `rich` for nice terminal output, `flask`/`fastapi` for
web services, `scipy` for numerical methods, `scikit-learn` for machine learning.
